# 赛博精神病院 · 专属抽象人设生成器

一个无需登录、无需模型 API 的手机网页小游戏。输入昵称、选择精神状态和可选线索后，系统会在本机组合生成一份荒诞人格档案。

## 使用

打开公开网址即可玩。也可以把 `dist` 目录上传到任何静态网站服务；`dist/index.html` 是入口，CSS 和 JavaScript 都是本地文件，不依赖外部字体、图片或付费接口。直接双击 `index.html` 也能运行，不过邀请链接应使用已经部署的网站地址。

## 功能

- 五种精神状态、五个可选线索、十八类身份库、多组能力、弱点和评语，昵称参与确定性组合。点击“重新生成”可得到新档案。
- 约三秒的扫描过程，按罕见程度改变档案颜色。
- 本地绘制 1080 × 1920 PNG，预览、下载、系统分享、复制文案和链接。
- 微信里如不能直接分享到朋友圈，可在图片预览中长按保存，然后从相册分享。

名字仅用于当前浏览器中的趣味生成，不会传到服务器。页面没有账户、统计脚本或实时 AI 推理。

## 文件

`dist/index.html`：页面结构；`dist/styles.css`：视觉与动画；`dist/app.js`：组合算法与图片绘制。

## 兼容说明

现代 Android Chrome、iOS Safari 和微信网页内核均支持页面使用的基础 HTML、CSS、Canvas API。系统分享是否提供“图片分享”、下载按钮是否直接保存到相册由浏览器和操作系统决定，页面提供长按图片保存的后备方式。未在真实安卓、iPhone 或微信设备上完成实机验证。
